📌 1. 이 계산기란?
NEIS(나이스) 학교생활기록부 입력 시 실제로 적용되는 바이트(Byte) 기준으로 글자 수를 실시간 계산합니다.
네이버 글자수 세기는 한글을 2바이트로 계산하지만, NEIS는 3바이트 기준이라 숫자가 다릅니다.
2025 ↔ 2026학년도 기재요령을 탭으로 전환하며 각기 다른 글자 수 기준을 적용할 수 있습니다.
2028대입 현 고2: 고1 기록은 2025학년도, 고2 기록은 2026학년도 기준 적용

문자 종류예시NEIS 바이트일반 포털(EUC-KR)차이

영문·숫자·공백a, 1, (space)1바이트1바이트동일
줄바꿈 (Enter)↵2바이트1~2바이트주의 필요
특수문자·한자!, ?, 漢3바이트2바이트+1바이트
💡
글자 수(환산)는 바이트 ÷ 3의 값으로, 모두 한글로 작성했을 때의 참고값입니다. 영문·숫자가 섞이면 실제 글자 수보다 환산값이 낮게 나올 수 있습니다. NEIS 제한은 항상 바이트가 기준입니다.
⚠
줄바꿈(Enter) 1회 = 2바이트 소모. 불필요한 줄바꿈이 많으면 글자 수가 빨리 줄어듭니다. 문단 구분이 필요 없는 경우 줄바꿈을 줄이세요.

🖊 4. 단계별 사용 방법
STEP 01
학년도 탭 선택
상단 탭에서 기재요령 연도를 선택합니다. 현재 고2는 고1 기록→2025년, 고2 기록→2026년 탭 사용.
STEP 02
내용 입력
각 항목의 텍스트 박스에 작성할 내용을 직접 입력하거나 붙여넣습니다.
STEP 03
실시간 확인
입력과 동시에 바이트·글자수·진행바가 자동 업데이트됩니다. 80% 이상→노랑, 초과→빨강 표시.
STEP 04
과목 추가/삭제
세특은 '+ 과목 추가' 버튼으로 과목을 추가하고, 과목명을 클릭하면 직접 수정할 수 있습니다.
STEP 05
복사 및 저장
항목별 📋 복사 버튼이나 하단 '전체 내용 복사' 버튼으로 NEIS에 붙여넣기 할 수 있습니다.
STEP 06
인쇄 / PDF
'🖨 인쇄/PDF' 버튼으로 입력 내용을 깔끔하게 출력하거나 PDF로 저장할 수 있습니다.
🎨 5. 색상 표시 의미
초록색 — 정상 범위 (80% 미만). 여유롭게 작성 중입니다.
노랑색 — 주의 구간 (80~100%). 내용 검토 후 필요 시 줄이세요.
빨강색 — 초과 (100% 초과). NEIS 입력 시 오류가 발생합니다. 반드시 수정하세요.
❓ 6. 자주 묻는 질문 (FAQ)
Q
네이버 글자수 세기로 500자인데 왜 NEIS에서 초과가 뜨나요?
네이버는 한글을 2바이트로 계산하지만 NEIS는 3바이트입니다. 한글 500자 = NEIS 1,500바이트 = 네이버 1,000바이트로 계산됩니다. 이 계산기를 사용하면 정확한 NEIS 기준값을 확인할 수 있습니다.
Q
봉사활동이 왜 50자밖에 안 되나요?
2026학년도 기재요령부터 봉사활동 활동내용이 250자→50자로 대폭 축소되었습니다 (교육부 기재요령 참고자료 8). 핵심 내용만 간결하게 기재해야 합니다.
Q
공통과목 세특은 어떻게 입력하나요?
공통국어1·2, 공통수학1·2, 공통영어1·2 등 공통과목은 1·2학기 합산 500자(1,500바이트)가 상한입니다. 1학기에 250자, 2학기에 250자씩 나눠 입력하거나 자유롭게 배분하되 합산이 500자를 넘지 않아야 합니다.
Q
입력 내용이 저장되나요?
현재 버전은 브라우저 세션 내에서만 유지됩니다. 창을 닫으면 내용이 사라집니다. 작성 후 반드시 📋 복사 버튼으로 내용을 저장하거나 🖨 인쇄/PDF로 보관하세요.
Q
현재 고2 학생은 어떤 탭을 써야 하나요?
현재 고2(2028대입)는 고1 때 기록과 고2 때 기록이 기준이 다릅니다. 고1 때(2025학년도) 입력한 내용 확인 → 2025년 탭, 현재 고2로 새로 입력하는 내용 → 2026년 탭을 사용하세요.
✨ 7. 효율적인 학생부 작성 팁
핵심 역량 중심으로 단순 활동 나열보다 '탐구 동기→과정→배움→성장'의 흐름으로 서술하세요.
글자 수가 줄었다고 내용도 줄지 않습니다. 2026학년도부터 행동특성 300자, 진로 500자지만 핵심만 간결하게 쓰면 더 인상 깊습니다.
영문/숫자를 활용하면 한글보다 바이트를 적게 씁니다. 예: '인공지능(AI)', '3단계 실험' 등.
AI 생성 문장 금지 — 2026학년도부터 ChatGPT 등 생성형 AI로 작성한 문장 활용이 공식 금지되었습니다.
